# Getting help

## Questions about using CuffScript

1. Look in the [documentation](docs/README.md). The [FAQ](docs/guide/faq.md) answers the questions beginners ask most, and the [error catalogue](docs/reference/errors.md) says what each error code means and how to fix it.
2. If it is not answered there, open an issue with the **Question** form: <https://github.com/cuffscript/cuffscript/issues/new/choose>. A question the documentation does not answer is a gap we want to know about, so asking is welcome.

A good question includes the smallest program that shows what you are asking about, the exact command you ran, and the complete output. The form asks for them.

## Something is broken

Open an issue with the **Bug report** form. [Contributing](CONTRIBUTING.md#reporting-bugs) says what makes a report easy to act on.

## A feature you would like

Open an issue with the **Feature request** form. [Contributing](CONTRIBUTING.md#proposing-features) explains how proposals are judged.

## A security problem

Please do not open a public issue for a vulnerability; follow the [Security Policy](SECURITY.md).

## Conduct

Everyone is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
